## 🔥 Key Features

1. **📐 Adaptive Dynamic Sidebar Layout:**
   - Eliminates layout shifting, cut-off rating stars, and overflowing sidebars when browsing with the F95Zone side navigation open.
2. **🖼 Direct Uncompressed HD Screenshots & Lightbox:**
   - Replaces low-res thumbnails with direct full-resolution images from image hosts. Includes a full-screen Lightbox viewer navigable with keyboard arrows or Esc.
3. **🎛 On-the-Fly Size Sliders:**
   - Adjust card grid sizes, banner widths, and screenshot dimensions to match your monitor and resolution.
4. **🔗 Cleaned & Direct Windows Mirrors:**
   - Unmasks obfuscated redirect links, prioritizes official Windows builds, and filters out dead mirrors.

## ⚙️ Installation & Automatic Updates

1. Install [Violentmonkey](https://violentmonkey.github.io/) (strongly recommended) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open the [**Direct Script Installation Link (v24.4)**](https://raw.githubusercontent.com/Terebonkoff/TGS-UserScripts/main/F95Zone_Enhanced_Suite.user.js).
3. Click **Confirm installation** in the browser tab.
