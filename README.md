## 🛠 Установка / Installation

1. Установите менеджер скриптов для вашего браузера:
   - [Violentmonkey (Рекомендуется)](https://violentmonkey.github.io/)
   - [Tampermonkey](https://www.tampermonkey.net/)
2. Нажмите на ссылку **«Установить / Install»** напротив нужного скрипта в таблице выше.
3. В открывшемся окне менеджера скриптов нажмите кнопку **«Установить»** (*Install*).
